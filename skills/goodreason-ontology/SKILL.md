# GoodReason Meta-ontology Reference

This plugin uses the GoodReason meta-ontology to organize work across four specialized agents.

## Eight Semantic Anchors (Compass Points)

| Symbol | Name | Meaning | Position |
| --- | --- | --- | --- |
| alpha | **Purpose** | Values, aspirations, goals, vision | North (N) |
| pi | **Theory** | Models, logic, concepts, abstractions | Northwest (NW) |
| chi | **Information** | Environment, data, observations, facts | West (W) |
| delta-psi | **Transformation** | Change pressure, transformation, evolution | Southwest (SW) |
| omega | **Feedback** | Monitoring, effects, goal-orientation | South (S) |
| tau | **Implementation** | Implementation, practice, integration | Southeast (SE) |
| phi | **Solution** | Solution, design, interface | East (E) |
| beta | **Structure** | Architecture, organization, hierarchy | Northeast (NE) |

## The 28 Pairwise Relationships

With 8 anchors there are exactly C(8,2) = 28 unique pairs. The core analytical discipline is to walk all 28 deliberately, asking "how does X relate to Y here?" and labeling each with an operator — insight lives in the relationships, not in the anchors alone. Escalate to triads (C(8,3) = 56) only when a pair cannot express a finding. See GOODREASON.md for the full pair list, worked examples, and common failure modes.

## Relational Operators

- **x (Resonance):** Parts reinforce each other
- **/ (Disconnection):** Systemic blindness between parts
- **interference:** Friction or active conflict
- **domination:** Destructive dominance
- **~ (Bridge):** Emerging contact or loose coupling
- **> (Priority):** Controlled dominance
- **=> (Transition):** Evolutionary progression
- **harmony:** Balanced reciprocal state
- **recursive:** Self-referencing feedback loop

## Anchor Health Levels

1. **Absent** — entirely missing
2. **Passive** — exists but has no effect
3. **Distorted** — present but corrupted
4. **Active** — healthy and vital

## Agent Topology

| Agent | Anchors | Role |
|-------|-----------|------|
| **Strategist** | alpha x chi | Analyzes goals vs. reality |
| **Architect** | pi x beta | Designs logic and structure |
| **Implementer** | phi x tau | Writes code and integrates |
| **Evolution** | omega x delta-psi | Tests and demands improvement |

## Workflow Cycle

1. **Strategist** assesses situation (goals vs. facts)
2. **Architect** creates structural plan with interfaces
3. **Implementer** writes code following the plan
4. **Evolution** tests and evaluates results
5. Feedback flows back to Strategist for next iteration

The main agent orchestrates this cycle, routing information and preventing disconnections.
